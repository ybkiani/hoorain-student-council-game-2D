# Hoorain's Student Council Adventure — Interactive 2D Edition

This keeps the original simple 2D game style and adds more interaction.

## New in this edition
- 8 short missions
- Leadership Star tap challenge
- Find Aisha's yellow notebook challenge
- More dialogue choices and rewards
- Animated achievement pop-ups
- VOTE FOR HOORAIN / YEAR 3 BRONZE wall poster
- Leadership and Kindness scoring
- Mobile-friendly buttons

## GitHub Pages
Upload `index.html`, `style.css`, `game.js`, and the `assets` folder to the root of the existing repository. Keep the filenames and folder structure unchanged.
